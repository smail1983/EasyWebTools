# EasyWebTools

Free, fast and simple online tools for everyday tasks.

## Current tools
- Image Compressor
- Image Resizer
- Word Counter
- Percentage Calculator
- Age Calculator
- Password Generator
- QR Code Generator

## Publishing
This project is designed for static hosting such as GitHub Pages.

Before using a custom domain, replace `YOUR-DOMAIN.example` in `robots.txt`, `sitemap.xml`, and the homepage canonical URL.

Also replace the placeholder contact email in `contact.html`.
