# EasyWebTools

Free, fast and simple browser-based tools for everyday tasks.

## Tools
- Image Compressor
- Image Resizer
- Word Counter
- Character Counter
- Text Case Converter
- Lorem Ipsum Generator
- Percentage Calculator
- Age Calculator
- Random Number Generator
- Password Generator
- QR Code Generator
- UUID Generator
- Base64 Encoder & Decoder
- JSON Formatter & Validator
- URL Encoder & Decoder

## Articles
Browse the complete guide directory at [articles.html](https://easywebtools.site/articles.html).

## Publishing
This project is designed for static hosting such as GitHub Pages. The primary domain is https://easywebtools.site/.

- `robots.txt` points to the XML sitemap.
- `sitemap.xml` lists the public homepage, tool pages, legal pages and article pages.
- Tool pages include canonical URLs, WebApplication structured data and helpful FAQs.
- The QR Code Generator loads its QRCode library from cdnjs; the QR image itself is generated in the browser.

## Privacy
Most tools process entered text, dates, numbers and selected images locally in the browser. Review [privacy.html](https://easywebtools.site/privacy.html) for the current details, including the third-party QR library. The password generator requires Web Crypto support.
