URL Encoder & Decoder

Encode or decode URL text instantly in your browser.

What does URL encoding do?

URL encoding converts characters that have special meanings in URLs into a safe encoded form. Decoding reverses that process.

About the URL Encoder & Decoder

URLs have reserved characters that separate parts of an address, such as the path, query string and parameter values. URL encoding converts characters that cannot safely appear in a particular URL component into percent-encoded bytes. Decoding reverses that transformation. This tool uses JavaScript's encodeURIComponent and decodeURIComponent functions, which are useful for encoding a query parameter or decoding a value copied from a web address. Encoding an entire URL and encoding one parameter value are not always the same operation.

How to use this tool

  1. Paste the text or URL component into the input field.
  2. Choose Encode to percent-encode characters in a component, or Decode to reverse valid percent-encoded sequences.
  3. Review the output and confirm it is being used in the correct part of the URL.
  4. If decoding fails, check for incomplete percent sequences or text that was encoded using a different convention.

Practical examples

  • Encode a search phrase such as 'coffee & tea' before placing it in a query parameter.
  • Decode a URL parameter to read spaces and punctuation in its original form.
  • Prepare a user-entered value for a link without changing the URL's structural separators.

Tips for better results

Use component encoding for individual query values. Do not blindly encode an entire URL if you need to preserve separators such as colon, slash, question mark and ampersand. Different URL contexts require different handling.

Frequently asked questions

What is percent encoding?

It represents bytes using a percent sign followed by two hexadecimal digits, allowing reserved or non-ASCII characters to be represented safely.

Should I encode a full URL or a parameter?

This tool uses encodeURIComponent, which is designed for a URL component such as a query parameter value.

Why does decoding show an error?

The input may contain an incomplete or invalid percent-encoded sequence.

Is my text uploaded?

No. Encoding and decoding use built-in JavaScript functions in the browser.
