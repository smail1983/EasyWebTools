How to Make a QR Code: URLs, Text, Printing and Scanning Tips

Learn how QR codes work, how to create one for a website or text, and how to test and print it clearly.

What a QR code is

A QR code is a two-dimensional barcode that stores information in a pattern of dark and light modules. A phone camera or QR reader can scan the pattern and interpret the encoded content. QR codes are often used to open a website, display short text, connect to a service or share information from printed materials. The code itself does not make a website trustworthy or guarantee that a destination is safe. It simply stores data that a compatible scanner can read.

How QR codes are read

A QR reader locates the square pattern, determines its orientation and decodes the modules into data. QR codes include error-correction information, which can help a scanner recover data if part of the pattern is damaged or obscured. The amount of data, the selected error-correction level and the size of the printed code affect how reliably it can be scanned. A dense code printed too small may be difficult for some cameras to read.

Choose what to encode

The most common use is a full website address, including its protocol such as https://. QR codes can also contain plain text, contact details or other supported data formats. Think about the person scanning the code and what they should see next. A short URL is often easier to scan and creates a less dense pattern than a long tracking-heavy address. Do not encode confidential data unless you understand that anyone who scans or photographs the code may read it.

Use QR codes on printed materials

QR codes can be placed on flyers, business cards, product labels, menus, posters and event signs. Leave clear space around the code so the scanner can distinguish it from nearby design elements. Use strong contrast between the foreground and background, and avoid placing the code over a photograph or textured surface. Choose a physical size that matches the scanning distance: a poster viewed from far away needs a larger code than a small card held close to a phone.

Test before publishing

Test the QR code with more than one phone when possible. Check that the correct page opens, that the destination uses HTTPS where appropriate and that the page works on mobile. Test the printed version rather than only the image on a desktop monitor. Paper texture, ink quality, reflections, folds and low contrast can affect scanning. If the QR code is part of an advertisement or public sign, check it after printing and after any change to the destination website.

Static and changeable destinations

A standard QR code stores the content directly. If it contains a URL, changing the destination later generally requires creating and printing a new code. Some services offer redirect links that can be updated, but the QR code then depends on the redirect service remaining active. If a campaign needs a destination that may change, use a domain and redirect system you control, and consider the service's reliability, privacy and long-term availability.

Privacy and safety considerations

A QR code can be photographed, copied and shared. Do not use it as a private storage mechanism for passwords, personal records or secret access tokens. When scanning a code from an unknown source, preview the destination before opening it and check the domain carefully. A malicious code can direct people to a phishing page or an unwanted download. Organizations should print a human-readable domain near the code so people can assess the destination before scanning.

Troubleshooting scan problems

If a code does not scan, first verify the encoded text and destination. Increase the printed size, improve contrast and leave a larger quiet zone around the pattern. Avoid stretching the image or converting it to a low-quality format. If the encoded data is very long, use a shorter URL where appropriate. Check whether the phone camera supports QR scanning and whether the code is in focus. Generate a new code if the source image has been distorted.

Frequently asked questions

Can a QR code contain a website link?

Yes. Enter the full URL, including https://, then generate and test the code.

Can I change the link after printing?

Not if the URL is encoded directly. Use a redirect URL you control if the destination may need to change.

Why will a QR code not scan?

It may be too small, distorted, low contrast, damaged or out of focus.

Does the generator use a third-party library?

Yes. The QRCode JavaScript library is loaded from a CDN; the QR pattern is generated in the browser.
