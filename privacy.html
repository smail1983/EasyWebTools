Privacy Policy

Last updated: November 25, 2026

EasyWebTools is designed to provide useful browser-based utilities while minimizing the information that needs to be sent to our servers. This policy explains what happens when you use the site. It should be updated whenever new third-party services, analytics, advertising or data collection features are introduced.

Information entered into tools

Most tools perform their main calculation in your browser using JavaScript and built-in browser APIs. The Image Compressor and Image Resizer read a selected image using a browser object URL and process it with the HTML canvas. Word Counter, Character Counter, Text Case Converter and Lorem Ipsum Generator operate on text in the page. Percentage Calculator, Age Calculator and Random Number Generator perform calculations in JavaScript. Password Generator uses the Web Crypto API and does not generate a password if secure browser randomness is unavailable. UUID Generator uses the browser's cryptographic UUID or random-byte API. Random Number Generator uses browser cryptographic randomness where supported and a non-cryptographic fallback for casual number selection; it is not intended for security-sensitive use. Base64 and URL conversion use built-in browser functions. JSON Formatter uses the browser's JSON parser and serializer. UUID Generator uses the browser's UUID or random-number functionality. These tools do not submit the entered content to an EasyWebTools processing endpoint.

Third-party resources and exceptions

The QR Code Generator loads the QRCode JavaScript library from the cdnjs.cloudflare.com content delivery network. The QR code pattern is generated in the browser, and the text you enter is passed to that library locally; the site does not send it to an EasyWebTools upload endpoint. However, loading a library from a third-party CDN causes the browser to make a network request to that provider, which may receive standard request information such as IP address, user agent and requested resource. Other pages may load standard site assets from this website. Review the third-party provider's policies if you want details about its processing.

Analytics, advertising and cookies

As of this policy update, the website repository does not include Google Analytics, Google Tag Manager, AdSense, Monetag or another identified analytics or advertising script, and the site code reviewed for this update does not intentionally set tracking cookies. The site does not currently describe an active analytics or advertising partner. If analytics, advertising, affiliate tracking or other cookie-based services are added later, this policy must be updated to identify the provider, purpose, data collected, cookie or storage technologies and available choices before those services are enabled.

Contact messages

If you use the Contact page, its form opens your device's default email application through a mailto link addressed to albadraouismail@gmail.com. The message is sent through your email provider, not through an EasyWebTools server. Your email provider's privacy practices apply to that communication.

Local storage and browser data

The tools do not require an account and do not intentionally store the content you enter on a remote EasyWebTools server. Your browser, operating system, extensions, clipboard, downloads folder or device backup may retain information according to your own settings. Clearing browser data or downloads is managed through your browser or device.

Security and limitations

Browser-side processing can reduce the need to upload data, but it does not guarantee that every part of your browsing session is private. Third-party browser extensions, compromised devices, network providers and external resources can operate independently of this website. Do not paste passwords, private keys, confidential business information or sensitive personal data into a website unless you are comfortable with the complete environment and its policies.

Children and changes

EasyWebTools is a general-purpose utility website and is not designed to collect personal information from children. We may update this policy when the site or its services change. The date above indicates when this page was last reviewed.
