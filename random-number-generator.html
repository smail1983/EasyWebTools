Random Number Generator

Generate a random whole number between your chosen minimum and maximum values.

—

How it works

Enter the minimum and maximum values, then generate a random whole number. The result is generated in your browser.

About the Random Number Generator

A random number generator selects a number from a range you define. It is handy for classroom activities, simple games, choosing a random item from a list or creating test values during development. This tool generates a whole number between the minimum and maximum values you enter, including both endpoints. Random results are useful for casual selection and demonstrations, but this page should not be used for lotteries, gambling, cryptographic keys or any process where independently audited randomness is required.

How to use this tool

  1. Enter the lowest whole number you want to include in the Minimum field.
  2. Enter the highest whole number in the Maximum field.
  3. Select Generate Number to produce a result.
  4. Change either boundary and generate again whenever you need another selection.

Practical examples

  • Choose a random page number for a classroom reading activity.
  • Generate sample integer values between 1 and 100 while testing a form.
  • Select a number from a defined range for a casual game or group activity.

Tips for better results

The tool rounds the minimum upward and the maximum downward to use whole-number endpoints. Check that the range contains at least one integer. For security-sensitive uses, use a dedicated cryptographic random generator and follow the relevant platform guidance.

Frequently asked questions

Are the minimum and maximum included?

Yes. The generator selects an integer from the inclusive range after rounding the entered boundaries to whole numbers.

Can I enter negative numbers?

Yes. Negative integer ranges are supported as long as the range is valid.

Is the result suitable for passwords or security keys?

No. Use a security-focused generator and cryptographic key-management practices for sensitive values.

Does the generator send my numbers to a server?

No. The calculation runs in your browser and does not submit the range to an EasyWebTools server.
